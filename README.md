# Pocket Wallet 💸

A secure, real-time personal expense tracker built for students to manage budgets and track daily spending.

## 🚀 Features
* **Google Authentication:** Secure private data vaults for every user.
* **Real-time Tracking:** Instant synchronization using Firebase Realtime Database.
* **Budget Management:** Visual progress bars for monthly spending limits.
* **PWA Enabled:** Installable on mobile devices for a native app experience.

## 📱 Mobile Installation (PWA)
You can install this app directly to your phone's home screen for quick access:
* **Android (Chrome):** Open the app link, tap the **three dots** in the top-right corner, and select **"Add to Home screen."**
* **iOS (Safari):** Open the app link, tap the **Share** button, scroll down, and select **"Add to Home Screen."**

## ☁️ Firebase Integration
* **Authentication:** Uses Google Sign-In to manage user identity and create private data silos.
* **Realtime Database:** Stores expenses and budgets in the cloud, syncing data instantly across devices.
* **Hosting:** Serves the web application globally via Google’s secure Content Delivery Network (CDN).

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6 Modules)
* **Backend:** Firebase (Realtime Database & Authentication)
* **Hosting:** Firebase Hosting
